# Console Snake Game

用 C++ 编写的经典控制台贪吃蛇游戏，在 Windows 终端中运行。

## 功能特点

- 纯 C++ 实现，无需任何外部依赖
- WASD 键实时控制蛇的移动方向
- 穿墙模式（从一侧出去会从另一侧进来）
- 实时计分系统
- 蛇身跟随增长效果

## 编译与运行

```bash
# 使用 g++ 编译
g++ snake.cpp -o snake

# 运行游戏
snake.exe
```

也可以使用 Visual Studio 的编译器：

```bash
cl snake.cpp
snake.exe
```

## 操作说明

| 按键 | 功能 |
|------|------|
| W | 向上移动 |
| A | 向左移动 |
| S | 向下移动 |
| D | 向右移动 |
| X | 退出游戏 |

## 游戏规则

- 控制蛇（O）吃掉食物（F），每吃一个得 10 分
- 每吃一个食物，蛇身会增长一节
- 撞到自己的身体则游戏结束
- 墙壁可以穿越，不会因撞墙死亡
